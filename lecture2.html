第二講 聲學基礎與心理聲學

耳朵是喇叭的一部分:本講從波動物理出發,建立「外耳即濾波器」的核心觀念,然後把「好聲音」從玄學變成科學 —— 目標曲線與偏好統計。

聲學物理心理聲學HRTF目標曲線Harman 研究
學習目標:修畢本講後,你應能 (1) 用波長尺度推理耳機各頻段行為的物理成因;(2) 推導耳道四分之一波長共振並解釋 3 kHz 耳增益;(3) 區分自由場 / 擴散場 / Harman 目標的理論基礎與適用場合;(4) 用頻段語言(而非形容詞)描述聲音差異。

§1 波動物理基礎(0:00–0:25)

1.1 聲壓與分貝:設計者的數字語感

聲音是空氣的壓力擾動。人耳可聞的壓力範圍極大:聽閾約 20 µPa,痛閾約 20 Pa —— 相差一百萬倍。因此採用對數尺度:

SPL = 20 · log₁₀(p / p₀) dB,p₀ = 20 µPa

設計者必須內化的數字語感:

  • +6 dB = 聲壓加倍(振膜位移加倍);+3 dB = 聲功率加倍(功耗加倍);+10 dB ≈ 主觀「兩倍大聲」。三者經常被混用,而它們的差別正是行銷話術的藏身處。
  • 常見基準:安靜房間 ~30 dB、對話 ~65 dB、通勤地鐵 ~80–90 dB、演唱會 ~100–110 dB。
  • 訓練有素的聽者能分辨約 0.5–1 dB 的寬頻電平差 —— 這個「恰可辨差(JND)」決定了一切工程公差,也決定了 A/B 測試為何必須電平匹配(±0.5 dB 內),否則「比較大聲」永遠贏。

1.2 波長:耳機聲學的第一直覺

第一直覺:看到頻響圖上的任何特徵,先算波長。低頻問題找「體積與洩漏」,中頻問題找「頭部與耳廓」,高頻問題找「腔體幾何與駐波」。這一條直覺能解釋耳機測量的八成現象。

§2 外耳聲學:耳朵是喇叭的一部分(0:25–0:55)

2.1 從肩膀到耳膜的增益鏈

自由空間中的聲音抵達耳膜前,依序經過:軀幹與肩膀反射(數百 Hz 起的細微起伏)→ 頭部繞射(高頻遮蔽、雙耳強度差)→ 耳廓(pinna)與耳甲腔(concha)的方向性反射(4–10 kHz 的凹陷與峰,是垂直定位的線索)→ 耳道共振。

耳道近似一端封閉(耳膜)、一端開放的管,長約 25 mm。閉管的第一共振為四分之一波長:

f₁ = c / 4L ≈ 343 / (4 × 0.025) ≈ 3.4 kHz

加上耳甲腔共振(約 4–5 kHz)的疊加,人耳在 2–4 kHz 區有 15–20 dB 的總增益 —— 這正是人聲子音、嬰兒哭聲所在的頻段;演化把我們的聽覺靈敏度峰值放在生存最需要的地方。

2.2 HRTF 與耳機的「劫持點」

上述整條增益鏈隨聲源方向而變,合稱頭部相關轉移函數(HRTF) —— 每個人的 HRTF 如指紋般獨特。耳機在這條鏈上的不同位置「接管」聲學:

形式劫持點設計後果
耳罩式耳廓之外保留耳廓與耳道濾波 → 個體差異自然發生;腔體與耳廓的交互作用成為高頻不確定性來源
非密封耳塞耳甲腔部分保留耳甲效應;無法密封 → 低頻先天不足
入耳式 IEM耳道中段完全繞過耳廓 → 必須把耳增益「做回」調音;插入深度改變殘餘耳道共振(約 7–9 kHz 半波駐波)
全課程最重要的心理聲學命題:耳膜處的目標響應,必須重建「優質音源在良好房間中、經過身體自身濾波後」原本會產生的結果。耳機越深入耳道,就越必須以電聲手段「假造」被繞過的解剖構造。

§3 心理聲學現象(0:55–1:15)

3.1 等響曲線:響度是頻率的函數

閱讀這張圖的三個設計結論:

  1. 小音量聆聽必然單薄:60 phon 與 80 phon 曲線在 50 Hz 的間距遠大於在 1 kHz 的間距 —— 音量轉小時低頻「消失得更快」。這是「響度補償(loudness)」EQ 與現代動態 EQ 功能的理論依據。
  2. 試聽音量是行銷武器:展示機音量調大 3 dB,低頻與高頻的主觀比例立即改變,聽感更「刺激」。專業評測必須以固定聲壓(如 75 dB SPL)校準。
  3. 調音必須指定基準音量:同一條頻響在不同聆聽音量下的主觀平衡不同 —— Harman 研究的偏好測試固定在中等偏大音量進行,這是引用其結論時必須記得的邊界條件。

§4 目標曲線:從物理推導到偏好統計(1:25–1:50)

4.1 為什麼「耳膜處平直」是錯的

在無響室中校準平直的喇叭,其聲音抵達聽者耳膜時已帶上 §2 的整條增益鏈 —— 一個以 3 kHz 為中心的大駝峰。若耳機在耳膜處測得平直,等於「抹掉」了這個駝峰,聽感必然黯淡、遙遠、不自然。因此耳機頻響必須對照「目標曲線」評價,而目標曲線的百年演進,就是「參考聲場該長什麼樣」的學術史:

4.2 三代目標曲線

世代曲線理論基礎評價
第一代
(物理推導)		自由場 FF(舊 DIN 45500)正前方無響室音源在耳膜產生的響應單一方向的假設不符聆聽真實;普遍過亮偏瘦
第一代改良擴散場 DF(Theile, 1986;IEC 60268-7 採納)全方向等能量入射之平均響應 —— 「理想混響室」大幅改善;成為錄音室耳機經典(Etymotic ER4、舊 AKG/Beyer);但多數人仍覺低頻不足
第二代
(偏好統計)		Harman 目標(Olive、Welti、McMullin,2013–2019)方法反轉:不再問「物理上該如何」,改問「受控盲測下,聽者把 EQ 調成什麼樣」。結果 ≈ DF + 低頻棚(耳罩 <100 Hz 約 +6 dB;入耳更多)+ 略收斂高頻;分 OE 2018 / IE 2019 兩版偏好分群:約 64% 屬「Harman 型」多數,另有嗜低頻群(偏年輕)與嗜平淡群(偏年長 / 受訓聽者);預測模型可由頻響偏差統計預測偏好分數
第三代
(治具革新)		B&K 5128 世代(JM-1、DF+tilt 等,2020s)新治具具解剖學正確的耳道與耳膜阻抗(有效至 20 kHz);以治具 DF 響應 + 可調「偏好斜率」(約 −0.8 至 −1.6 dB/oct)+ 可調低頻棚取代單一曲線把「一條神聖曲線」改寫為「曲線族 + 偏好參數」;2024–25 追蹤研究顯示 Harman 式調音仍獲 ~72% 偏好,與新曲線統計持平

4.3 目標曲線的正確使用方式

  1. 它是統計中心,不是物理定律。偏離目標 = 偏離多數人偏好的機率上升,僅此而已。品牌「house sound」是有意識的偏離:Sennheiser 的暖中性、Beyerdynamic 的高頻抬升、Sony 消費線的低頻 —— 是定位,不是誤差。
  2. 指定治具再談曲線。同一副耳機在 711 耦合器與 5128 上的曲線形狀不同;跨治具比較曲線是資料素養的常見翻車點。8 kHz 以上的窄峰谷多為治具假影,只看趨勢不看單點。
  3. 公差語言:工程規格寫法如「Harman OE 2018,±2 dB(100 Hz–8 kHz)、±3 dB(全頻)」;±1 dB 的寬帶偏差已屬可聞,耳增益區 ±3 dB 即是明顯的性格差異。
  4. 空間音訊的伏筆:雙耳渲染內容已在訊號中內含 HRTF —— 播放端若再套用完整耳增益目標會「重複計算」;AES 前沿研究指向接近 DF-flat 的空間音訊專用目標。此題在第六講「未來趨勢」回收。

§5 聆聽實驗:三條曲線盲聽(1:50–2:00)

示範:同一副 IEM,以 AutoEQ 分別校至 (a) Harman IE 2019、(b) 擴散場、(c) 耳膜平直。全班盲聽投票並用頻段語言記錄差異。預期結果:(c) 普遍被形容為「悶、遠」;(b) 被形容為「乾淨但薄」;(a) 獲多數偏好但有少數聽者選 (b) —— 現場重演偏好分群。

重點整理

本講五個帶得走的觀念:
  1. 先算波長:低頻找體積與洩漏、中頻找頭部、高頻找腔體幾何 —— 一條直覺解釋八成測量現象。
  2. 耳道四分之一波長共振(≈3.4 kHz)+ 耳甲共振 = 15–20 dB 耳增益;耳機越深入耳道,越要以調音重建它。
  3. JND ≈ 0.5–1 dB:它定義工程公差,也定義「沒有電平匹配的 A/B 都是騙局」。
  4. 目標曲線三代史 = 從物理推導(FF/DF)到偏好統計(Harman)到曲線族 + 參數(5128 世代)。
  5. 目標是統計中心;house sound 是有意識的偏離,是定位語言而非誤差。
