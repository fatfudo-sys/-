第三講 換能器技術與電聲系統設計

「力如何施加在振膜上」決定了一切:失真、頻寬、成本。本講先講五大換能器,再講單體以外的三分之二 —— 腔體、測量、電氣匹配與 ANC/DSP 系統。

動圈平板磁性靜電動鐵 BA腔體聲學ANC
學習目標:修畢本講後,你應能 (1) 依「驅動方式 → 失真/頻寬/成本輪廓」的因果鏈比較五大換能器;(2) 以集中參數模型解釋前腔、後腔、洩漏與阻尼的調音角色;(3) 完成靈敏度/功率匹配計算;(4) 說明混合式 ANC 的控制迴路與物理極限。

§1 五大換能器架構(0:00–0:35)

1.1 動圈(Moving-coil / Dynamic)—— 市場的 95%

原理:音圈黏著於振膜頂點、懸於環形磁隙中,通電後受勞侖茲力:

F = B · l · i
B:磁隙磁通密度(T) l:線圈總長(m) i:電流(A)

解剖:振膜(球頂 + 懸邊)、音圈(銅或銅包鋁 CCAW)、磁體(釹鐵硼為主)、導磁板構成磁隙、支架與調諧孔。

懸邊剛性 + 移動質量決定基頻共振 f₀(耳罩式典型 60–120 Hz);f₀ 以下輸出滾降,f₀ 以上進入質量控制區。

優勢弱點對應設計手段
大衝程 → 低頻能力強;高靈敏度(手機直推);成本低;單一單體覆蓋 20 Hz–20 kHz;耐用「點驅動」使振膜高頻進入分割振動(break-up)→ 高頻峰與粗糙感;音圈質量限制暫態;磁路非線性(B·l 隨衝程變化)→ 低頻諧波失真提高振膜比模數(鍍鈹、DLC、LCP)把 break-up 推出可聞區;CCAW 減輕音圈;加大磁通、優化磁隙對稱性;後腔阻尼控制 Q 值

1.2 平板磁性(Planar magnetic)

原理:把「音圈」攤平印在整張薄膜上(蛇形導體走線),兩側(或單側)排列條狀磁陣 —— 驅動力均勻分布於整個振膜表面(面驅動),振膜近似理想活塞運動,從機制上消滅了分割振動與磁隙非線性兩大動圈弱點。

  • 優勢:全頻段低失真(尤其低頻,94–100 dB SPL 下 THD 常 <0.1–0.5%);暫態均勻;大輻射面積使低頻毫不費力;阻抗近純電阻且平坦(對擴大機音色友善)。
  • 弱點:磁陣重(旗艦歷史上 400–700 g,單側磁陣漸改善);靈敏度低(常需 数百 mW,見 §4 計算);張膜與組裝成本高;磁條部分遮蔽聲路,需聲學整形(Audeze Fazor 導波片、HiFiMAN 隱形磁體)。
  • 代表:Audeze LCD 系列、HiFiMAN Susvara/Arya、Dan Clark Audio(附 AMTS 調諧共振器)、Meze Elite。

1.3 靜電(Electrostatic)

原理:1–2 µm 的聚酯膜鍍上高阻抗塗層、充至高壓直流偏壓(Stax Pro 規格 580 V),懸於兩片開孔定子之間;音訊訊號經升壓後加於定子,靜電場對帶電膜施力 —— 同樣是面驅動,且移動質量接近空氣本身。

  • 優勢:所有技術中最低的移動質量 → 極致細節、中高頻失真近乎消失、頂部延伸無縫。
  • 弱點:需專用高壓耳擴(energizer);最大聲壓與低頻衝程受定子間距限制;怕塵怕濕;成本高。
  • 代表:Stax SR-009S/X9000、Sennheiser HE-1、Audeze CRBN、Shure KSE1200(靜電 IEM)。

1.4 動鐵 BA(Balanced Armature)—— IEM 的主力

原理:微型簧片(銜鐵)平衡懸於磁隙中,線圈電流使其失衡偏轉,經驅動桿推動微振膜,聲音由出聲嘴(spout)導出。源自助聽器產業,Knowles 與 Sonion 雙寡佔供應。

  • 優勢:極小(一殼可塞多顆)、高效率、中高頻解析佳、密閉結構利於隔音。
  • 弱點:單顆頻寬窄 → 多單體 + 被動分音(電容電阻網路)+ 導管長度調諧 + 聲學阻尼(Knowles 色碼阻尼,以 rayl 值規格);衝程小 → 低頻靠洩壓式 BA 或混合動圈低音;阻抗隨頻率劇烈擺動 → 對訊源輸出阻抗敏感(§4)。

1.5 混合式與新分支

架構組成要點
混合 / 三混 IEM動圈低音 + BA 中高 +(電子靜電 EST 或壓電超高音)設計難點是「一致性」:相位、靈敏度、音色跨異質單體的銜接,靠分音與導管幾何解決
AMT 氣動摺疊振膜如手風琴擠壓空氣空氣速度為膜速 4–5 倍 → 高頻極快;重量與低頻是代價(HEDDphone)
MEMS矽基微機電壓電驅動固態、晶圓級一致性、相位精準;TWS/IEM 高音與全頻新分支(xMEMS),需偏壓驅動 IC —— 本課指定的「值得下注的新技術」
骨傳導 / 電璽 / 壓電顱骨振動 / 永久駐極體 / 晶體彎曲運動開放聆聽、低成本耳塞、超高音補充 —— 各有生態位

§2 腔體聲學:單體只是三分之一的故事(0:35–1:05)

2.1 集中參數模型(設計者的心智模型)

低頻時(波長 ≫ 尺寸),整個耳機等效為一個電路 —— 這不是比喻,而是可以直接丟進 SPICE 求解的嚴格類比:

聲學元件電路類比實例
密閉空氣體積(順性)電容 C前腔、後腔、耳墊泡棉;體積越大電容越大
孔道中的空氣柱(質量)電感 L洩壓孔、調音孔、IEM 導管;孔越長越細電感越大
阻尼 / 洩漏(阻性損耗)電阻 R調音網布(以 rayl 規格)、耳墊與頭部之縫隙
振膜RLC 串聯支路質量 L、懸邊順性 C、機械損耗 R → f₀ 共振

大廠流程:先建集中參數模型(或 COMSOL / AKABAK 模擬)掃參數,確定腔體、孔徑、阻尼值的設計窗,再開模 —— 模具動輒數十萬美元,「先模擬後開模」是產業紀律。

2.2 三個決定性的低頻機制

  1. 壓力腔效應(耳機低頻的秘密):密閉前腔中、第一共振以下,耳膜聲壓正比於振膜位移而非加速度 —— 頻率下降輸出不衰減。這就是 10 mm 單體平直重播 20 Hz 的原理,也是喇叭永遠學不來的耳機特權。
  2. 洩漏 = 高通濾波器:洩漏孔(電感+電阻)與前腔電容構成高通;縫隙越大截止頻率越高。耳墊與頭部之間幾 mm² 的縫隙即可削去 100 Hz 處數 dB —— 戴眼鏡低頻變少的定量解釋。設計必須選邊:耐洩漏(預先大開孔 + DSP/ANC 補償低頻,AirPods Pro 路線)或依賴密封(低頻最大化,配戴敏感,發燒 IEM 路線)。
  3. 後腔 / 後孔 = 阻尼與 Q 值:後腔電容與後孔電感構成的網路決定 f₀ 附近的 Q;覆以阻尼網(電阻)可壓平共振峰。開放式等於「後腔電容無限大 + 零反射」→ 響應平滑但失去壓力腔 → 低頻靠大振膜面積補。

2.3 高頻(模態)區與 IEM 特論

  • 約 1–2 kHz 以上集中參數失效:前腔出現駐波、耳廓幾何介入、耳墊形狀成為波導。手段:斜置單體(模擬近場喇叭入射角,HD 600 系、Audeze)、波導與整流環(Focal M 型盆 + 護網幾何、DCA AMTS 吸收特定高頻模態)、阻尼貼放(羊毛氈、微孔板貼於模態壓力極大點)。
  • 耳墊即調音件:墊深改變前腔體積(低頻與 3 kHz 增益)、開口形狀改變耳廓交互、表面材質(皮革=密封反射,絨布=洩漏吸收)在低頻量與高頻平滑度間交換。換墊 = 換耳機;墊圈老化 = 調音漂移。
  • IEM:耳塞至耳膜的空氣柱半波共振約 7–9 kHz,隨插入深度移動(深插推高出可聞敏感區 —— Etymotic 哲學);導管內徑 + 分岔網路 = 被動濾波;前洩壓孔解堵耳與「驅動膜吸附」(driver flex),後調音孔塑造動圈低頻。矽膠 / 記憶泡棉耳塞改變密封與高頻吸收 —— 交給使用者的最後一個調音變數。

§3 測量體系(1:15–1:35 前半)

治具本質適用與限制
IEC 60318-4「711」耦合器模擬堵塞耳道聲阻抗的標準腔IEM 數十年標準;約 8 kHz 以上出現治具假影,高頻只看趨勢
GRAS 43AG / KEMAR耳頰模擬器 / 含耳廓之頭軀模擬人耳罩式與 ANC 測試主力;耳廓材質軟硬影響密封與低頻
B&K 5128 HATS解剖學正確之耳道與耳膜阻抗,有效至 20 kHz研究級新標準;舊目標曲線不能直接搬用 → 催生第三代目標(第二講)

核心測量集:頻響與左右配對、THD 對頻率與聲壓(動圈低頻大聲壓時上升;優秀平板 <0.1–0.5%)、阻抗與相位曲線(動圈 f₀ 處阻抗峰;多路 BA 的分音痕跡)、靈敏度、隔音(被動+主動)、外洩(辦公室禮儀規格)、脈衝響應 / CSD 瀑布圖(共振殘響)、群延遲與系統延遲(>20 ms 影音不同步;遊戲需 <40 ms 端到端)。產線 100% 執行掃頻異音檢測(rub & buzz,Klippel / Listen SoundCheck,每台數秒)。

§4 電氣匹配:阻抗、靈敏度與功率(1:35 前完成)

4.1 阻抗與八分之一法則

訊源輸出阻抗 Zout 與耳機阻抗 Zhp(f) 構成分壓;若 Zhp 隨頻率擺動而 Zout 不可忽略,分壓比就隨頻率變 → 頻響被改寫。

法則:Z_out ≤ Z_hp(min) / 8
例:某多路 BA IEM 阻抗 8–60 Ω 擺動 → 訊源輸出阻抗需 ≤ 1 Ω,否則音色隨訊源改變

高阻抗耳機(250–600 Ω,Beyerdynamic 傳統)存在的理由:更細的音圈線 → 更輕的音圈 → 更好的高頻;歷史上廣播台多副並聯的制度慣性;對訊源雜訊電壓不敏感。

4.2 靈敏度與功率預算(工作例)

P = 10^((SPL_target − Sens_dB/mW) / 10) mW
例 1:靈敏度 100 dB/mW,目標峰值 110 dB → 10^(10/10) = 10 mW(手機即可)
例 2:平板 83 dB/mW,同目標 → 10^(27/10) ≈ 500 mW(需桌上型耳擴)
換算:dB/V = dB/mW + 10·log₁₀(1000/Z);100 dB/mW @ 32 Ω ≈ 115 dB/V

線材與平衡驅動的工程事實:可測的線材效應本質上是電阻(電平與阻尼)與極端情況下的電容(IEM);多數「換線聽感」可追溯至密封、配戴與電平變化。平衡驅動加倍電壓擺幅、消除共地串音 —— 對難推負載與長線有實益,並非天生「更好聽」。現代 DAC 晶片(SNR >110 dB、THD <0.001%)已超越換能器極限;訊源的可聞差異主要來自輸出阻抗、功率上限與 DSP,而非解碼晶片。

§5 ANC 與 DSP 系統(1:35–1:55)

拓撲麥克風特性
前饋 FF外側,先聽到噪音「預測式」抵銷;主要 <1 kHz 有效;預測錯誤=加噪;怕風噪
回授 FB內側,聽耳內殘餘頻寬較廣、自動修正配戴差異;迴路穩定性(嘯叫)是經典控制問題
混合 Hybrid內外兼備旗艦標配;100–300 Hz 可達 30–45 dB 衰減;成本=兩組好麥克風+強 DSP
  • 次級路徑問題:「單體 → 耳膜」轉移函數隨每次配戴、每副眼鏡、每種髮型改變;自適應濾波(FxLMS 家族)與入耳校正音持續重新辨識此路徑 —— 這是 ANC 從「電路」變成「演算法」的分水嶺。
  • 物理極限:波長太短即無法單點抵銷 → ANC 僅 ~1–2 kHz 以下有效;高頻交給被動隔音。總衰減 = 被動 + 主動,兩者的交接頻率是系統級規格。
  • 副作用工程:低頻壓力調變之「耳壓感」(eardrum suck)、前饋麥克風風噪(網罩 + 偵測切換)、麥克風/ADC 自體噪聲底、堵耳效應補償。通透模式是 ANC 的反函數 —— 自然地重播外界 + 處理自己的聲音,工程上比降噪更難。
  • DSP 堆疊全景:出廠調音 EQ → 使用者 PEQ → 心理聲學低音 → 動態響度補償 → 配戴自適應(回授麥克風實測入耳響應、自動補低頻)→ 空間音訊(IMU 頭部追蹤 + 個人化 HRTF)→ 聽力個人化(聽力圖增益,已入 OTC 助聽監管領域)→ 通話(波束成形 + 骨導感測 + AI 降噪)。
  • 藍牙鏈路:SBC(基準)→ AAC(Apple 生態)→ aptX 家族 / LDAC(至 990 kbps)→ LE Audio LC3(同碼率更佳品質、更低延遲、Auracast 廣播)。延遲:SBC/AAC 約 150–250 ms;遊戲模式 / LC3 約 40–80 ms;真正口型同步需 2.4 GHz 私有協定(<20 ms)。
課堂討論:為什麼「通透模式做得自然」比「降噪做得深」更難?提示:從次級路徑、堵耳效應、自體聲音三個方向論證。

重點整理

本講五個帶得走的觀念:
  1. 驅動方式決定命運:點驅動(動圈)→ 分割振動;面驅動(平板/靜電)→ 低失真但低靈敏度/高成本;槓桿驅動(BA)→ 微型但窄頻寬。
  2. 集中參數模型:腔體=電容、孔道=電感、阻尼=電阻 —— 低頻調音就是在解一個 RLC 電路。
  3. 壓力腔效應是耳機低頻的特權;洩漏是它的天敵;產品必須在「耐洩漏」與「依賴密封」間選邊。
  4. 八分之一法則與功率預算計算,是「需不需要耳擴」的唯一科學答案。
  5. ANC 的本質是自適應控制(次級路徑追蹤),物理極限在 1–2 kHz;總衰減=被動+主動。
