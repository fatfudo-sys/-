第四講 工業設計、人因工程、材料與結構

耳機是被夾在「人體最精密也最多變的部位」上的工程物。本講把舒適變成數字、把材料變成規格、把量產變成品質體系 —— 並在最後面對設計者無法迴避的永續責任。

人因工程工業設計CMF材料科學結構製造DFM
學習目標:修畢本講後,你應能 (1) 以夾持力、峰值壓力、重量與熱指標量化配戴設計並完成計算例;(2) 依「比模數 + 內阻尼」評選振膜與殼體材料;(3) 描述從單體配對到端末 100% 檢測的量產品質體系;(4) 將可維修性納入設計決策。

§1 人因工程:把舒適變成數字(0:00–0:30)

1.1 人體計測基礎

耳機的「安裝面」規格來自人體計測資料庫(現代大廠使用數千人的 3D 頭部掃描):

參數典型成人範圍影響的設計項
頭寬(雙耳上方)約 135–165 mm頭帶展開量與夾持力曲線
頭頂至耳道弧長約 300–380 mm滑軌行程(需覆蓋 5–95 百分位)
耳廓高度約 55–70 mm耳墊內腔開口(耳廓不可觸底或折壓)
耳道直徑 / 角度直徑約 7–9 mm,朝前下傾耳塞尺寸階(S/M/L + 橢圓)、IEM 出音嘴角度

關鍵素養:各人群(性別、年齡、族群)分布差異顯著,單一幾何無法全球通用 —— 這是耳塞附多尺寸、頭帶大行程、以及客製耳模市場存在的統計學原因。

1.2 夾持力與壓力分布(計算例)

耳罩式的實務舒適窗:總夾持力約 3–6 N(以 145–155 mm 標準頭治具量測)。>5–6 N 多數人一小時內明顯疲勞;<2 N 則晃動且低頻密封失效(第三講:洩漏=高通)。但夾持力只是入口,真正決定舒適的是峰值壓力:

平均壓力 P = F / A
例:F = 5 N,耳墊接觸面積 A = 35 cm² = 3.5×10⁻³ m² → P ≈ 1.4 kPa(舒適)
同樣 5 N 若集中於 8 cm²(小耳墊 / 壓耳式)→ P ≈ 6.3 kPa(半小時即痛)
參考:微血管灌流壓約 4 kPa —— 長時間超過即產生壓迫性不適
  • 結論一:「更大、更深、更軟」的耳墊不是奢侈,是壓力管理工程;耳廓絕不可觸及單體護網(點壓力 + 高頻染色雙重災難)。
  • 結論二:壓耳式(on-ear)天生吃虧 —— 壓力直接落在耳廓軟骨;同樣夾持力下不適速度遠快於耳罩式。
  • 重量預算:<250 g「戴著會忘記」;300–400 g 需寬頭帶 / 懸吊帶分載(顱頂壓力同樣適用 P=F/A);>450 g(部分平板旗艦)無論如何限制時長。耳殼深度造成的頸部力矩與克重同等重要 —— 重心離頭部旋轉軸越遠,轉頭的慣性負擔越大。
  • 熱舒適:皮革 / 蛋白皮密封佳但鎖熱鎖濕(耳周皮膚溫升 2–4 °C 即感悶熱);絨布透氣但洩漏低頻。這是真實的物理取捨,不存在兩全的材料,只存在為目標情境做的選擇(通勤 ANC → 密封;家用長聆聽 → 透氣)。

1.3 機構設計:每個關節都是規格

  • 滑軌:段落式(可重複定位、有刻度感)vs. 平滑式 vs. 自適應懸吊(AKG 傳統);行程須覆蓋 5–95 百分位頭型。
  • 軛與轉軸:耳殼需要俯仰 + 旋轉兩個自由度貼合頰平面;自由度不足 → 墊圈局部洩漏 → 左右低頻不對稱(測量可見!)。
  • 摺疊鉸鏈:經典疲勞破壞點(金屬疲勞 + 塑膠蠕變);規格語言:開合 >50,000 次無功能劣化。
  • 異音控制:耳機是把「震動感測器」戴在耳邊 —— 任何機構微動、線材摩擦(microphonics)都被放大;解方:預壓配合、阻尼油、線材編織外皮與過耳繞線。機構噪音是正式測試項目,不是主觀抱怨。

§2 工業設計與 CMF(0:30–0:55)

  • CMF 方法:Color(色彩計畫:主色 + 材質色 + 點綴色)、Material(觸感與重量感的來源)、Finish(表面處理:陽極、PVD、咬花、軟觸漆)。耳機是「穿戴物」—— CMF 同時對佩戴者與旁觀者說話,這是它與家電 CMF 的根本差異。
  • 辨識度資產:AirPods 的白色柄、Beats 的「b」、HD 800 的銀色鏤空、B&O 的鋁盤 —— 100 公尺外可辨識的輪廓是行銷資產負債表上的真實資產(第五、六講案例展開)。
  • 控制介面:實體鍵(盲操作可靠、有廉價感風險)vs. 觸控(乾淨、誤觸與手套問題)vs. 旋鈕冠(AirPods Max 的數位錶冠 —— 精密機械感即豪華感)。TWS 特有難題:控制面 = 換能器外殼,敲擊聲直接進耳 → 需機構去耦或 DSP 靜音遮罩。
  • IEM / TWS 配戴幾何:耳甲鎖定(concha-lock)翼型、出音嘴前下傾角、柄式(重心外移、麥克風靠嘴)vs. 豆式(隱蔽、重心入耳);運動線 IPX4 起跳、真運動線 IPX7。客製耳模(CIEM)是配戴的天花板:取模 / 3D 掃描 → 樹脂列印殼體;代價是轉售價值歸零與耳型隨年齡改變需重製。

§3 材料科學:振膜、磁體、殼體(1:05–1:30)

3.1 振膜材料:比模數的競賽

振膜要「輕而剛、剛而有阻尼」。品質因數是比模數 E/ρ(勁度除以密度,決定分割振動頻率上限)與內阻尼 tan δ(決定共振峰的自我抑制):

材料楊氏模數 E (GPa)密度 ρ (g/cm³)比模數 E/ρ評註
PET / Mylar~41.40~3基準材料;便宜、阻尼佳、易熱成形
PEEK / PEN 多層膜4–61.3~4耐溫佳;多層複合可調阻尼
LCP 液晶聚合物~10+1.4~7TWS 高階常客(剛性升、仍有聚合物阻尼)
生物纖維素~301.2~25Sony R10 / Fostex 傳統;「紙的極致」,音色評價極高
鋁692.70~26金屬入門;需鍍層或複合抑制金屬鈴振
鈦1104.5~24耐用;鈴振明顯,多作鍍層
鎂451.74~26比模數同鋁但阻尼更佳
鈹 Be2871.85~155可用材料之王(Focal Utopia 純鈹盆);粉塵毒性 → 加工昂貴
DLC / CNT / 「石墨烯」鍍層鍍層有效勁度提升——本質是「聚合物膜 + 硬鍍層」複合;行銷經常跑在物理前面,讀規格書時務必追問基材
資料素養:「石墨烯振膜」十之八九是 PET 膜加奈米碳鍍層。判讀方法:問三個數字 —— 基材是什麼?膜厚多少?break-up 頻率推到哪?答不出來的,是行銷部寫的規格。

3.2 磁體與馬達

  • 釹鐵硼 NdFeB(N48–N55)為主流:磁能積越高、磁隙磁通越強 → 靈敏度與阻尼越好;代價是耐溫性(高牌號需鏑摻雜)與成本。鐵氧體存活於入門線(便宜、耐溫、弱磁)。
  • 平板磁性的成本結構:磁陣佔其 BOM 與重量的大宗 —— 單側磁陣(犧牲部分驅動對稱性)是近年減重降價的主要路徑。
  • 製程紀律:充磁後組裝需要防磁吸自動化;磁隙潔淨度是良率生命線 —— 0.5 mm 磁隙中的一粒鐵屑 = 刮圈異音 = 一件退貨。

3.3 殼體與結構材料

材料 / 製程用途選用邏輯
ABS / PC(射出,玻纖強化)耳殼、滑軌、內構成本、成形自由度;玻纖提升剛性但增加脆性;咬花掩飾縮水痕
鋁(CNC / 沖壓 + 陽極)外觀件、軛精密感與散熱;CNC 貴、沖壓需分攤模具

不鏽鋼簧片頭帶芯夾持力曲線的來源;疲勞壽命設計點

§4 量產與品質體系(1:30–1:50)

  1. 單體廠振膜熱成形 → 音圈繞製與貼合(膠量以 mg 計)→ 充磁 → 自動組裝。每顆單體 100% 測量、分級,並以頻響曲線配對為左右聲道(高階線 ±0.5–1 dB)—— 「配對」是高階耳機成本的隱藏項。
  2. 整機組裝腔體組裝與阻尼貼放(位置公差以 0.5 mm 計,依賴治具 + 人工手感)、墊圈、頭帶、焊線或無線主板落板。設計時的 DFM(可製造性設計)決定此站良率:能不能防呆?阻尼會不會貼反?
  3. 端末 100% 檢測迷你消音箱內數秒完成:頻響遮罩比對、掃頻異音(rub & buzz)、極性、麥克風(耳麥產品);Klippel / Listen SoundCheck 為業界標準設備。抽樣再做 THD 與隔音全項。
  4. 可靠度驗證(出貨前的酷刑室)1 m 六面落下、滾筒翻落、線材彎折 >10k 次、頭帶開合 >50k 次、汗液/鹽霧、UV 曝曬、−20/+60 °C 溫度循環、墊圈磨耗模擬、按鍵壽命;TWS 追加:充電盒鉸鏈壽命、電池循環(500 次後容量 ≥80%)、IP 等級水槽實測、UN 38.3 電池運輸認證。
成本解剖(主流無線耳罩,示意):換能器數美元;SoC + 電池 + 麥克風陣列 + 機構與 CMF + 各國認證構成 BOM 主體;韌體與 App 團隊是持續性最大研發支出。「維持第 100,000 台與金樣品一致」—— 治具相關性、單體配對統計、產線 Cpk —— 是消費者永遠看不見、卻決定品牌壽命的戰場。

§4.5 永續與可維修(併入本節)

  • 失效順序的真相:電池(2–4 年)與墊圈(1–3 年)遠早於單體(數十年)死亡。膠合電池使 TWS 成為拋棄式品類 —— 每年數億副電子垃圾。
  • 法規正在到來:歐盟電池法規與維修權立法,將「可換電池、零件供應、維修文件」從美德變成合規要求。
  • 設計對策:模組化(可換墊圈 / 線材 / 電池 —— HD 25、HD 600 全件可換是長壽典範;Fairbuds 示範可換電池 TWS)、標準接頭優先於專有、韌體支援年限承諾、再生塑料 / 鋁與無塑包裝。
  • 永續 = 聲學:可換墊圈同時恢復原廠調音 —— 密封墊圈老化即調音漂移,不可換墊的設計等於「內建過期日」。

§5 評圖演練(1:50–2:00)

課堂演練:兩款市售耳機(一款 US$60 電商爆款、一款 US$400 旗艦)傳閱,各組以本講語言完成 5 分鐘快評:夾持力估計、峰值壓力風險點、材料與表面處理判讀、兩個 DFM 疑點、一個可維修性紅旗。重點不是結論,而是用數字和製程語言說話。

重點整理

本講五個帶得走的觀念:
  1. 舒適是可計算的:P = F/A,對照微血管灌流壓 ~4 kPa;夾持力窗 3–6 N;重量預算分級管理。
  2. 振膜看兩個數:比模數 E/ρ(推高 break-up)與內阻尼 tan δ(自抑共振)—— 行銷名詞後面永遠追問這兩個數。
  3. 鎂合金是高階耳機的隱形冠軍;阻尼網以 rayl 值採購 —— 材料在耳機業是以「聲學參數」被規格化的。
  4. 高階品的隱藏成本在「配對」與「一致性」:單體 100% 測量分級、產線端末 100% 聲學檢測。
  5. 電池與墊圈先死:可維修性是聲學壽命、商業誠信與即將到來的法規三合一問題。
課後作業 4(6%):對一款耳罩式耳機執行完整「人因稽核」:實測或估計夾持力與接觸面積(計算平均壓力並與 4 kPa 對照)、稱重、記錄 1 小時配戴之熱與壓力主觀量表(每 15 分鐘一次),提出兩項具體改良設計(1,000 字 + 圖表)。
