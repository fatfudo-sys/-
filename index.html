1.1 演變史:五次使用情境轉移

耳機史的關鍵不是技術年表,而是五次使用情境轉移,每一次都重寫了設計規格的優先順序:

轉移時期驅動事件設計規格的改寫
通訊 → 音樂欣賞1958Koss SP/3、立體聲唱片普及從語音頻寬轉向全頻段保真;「Hi-Fi」成為規格語言
居家 → 隨身1979Sony Walkman重量、體積、靈敏度(電池驅動)壓倒一切;開放式輕量結構(MDR-3)
聆聽 → 專業工具1980–90s舞台 IEM、錄音室標準機隔音、配戴穩固、可維修性、單體一致性成為核心規格

1.2 市場結構(以 2020 年代中期為基準)

  • 規模與量值:全球耳機市場約 500–600 億美元量級,年出貨以「億副」計;其中 TWS 佔銷售額與出貨量之最大宗(單位佔比逾六成),年出貨約 3 億副量級。
  • 價格帶金字塔:入門(<US$50,量最大、白牌與新興市場品牌主導)→ 主流(US$50–250,Sony / Bose / Apple / Samsung 廝殺 ANC 與生態系)→ 發燒(US$250–2,000,Sennheiser / Focal / 平板磁性品牌)→ 旗艦 / 靜電(US$2,000–60,000,Stax、Sennheiser HE-1 等,行銷意義大於營收)。
  • 品牌市佔格局:TWS 由 Apple 領先(約四分之一強),其後為 Samsung、小米、boAt(印度)等;傳統耳罩市場則高度分眾。
  • 區域特徵:北美重 ANC 與通勤、日本存在深厚發燒文化與器材店通路、中國崛起「Chi-Fi」性價比 IEM 生態(第六講詳述)、印度為入門 TWS 最大成長引擎。

2.1 外耳聲學:設計者必須內化的一張圖

自由空氣中,耳廓、耳甲與耳道對聲音施加隨方向而異的濾波 —— 頭部相關轉移函數(HRTF)。耳道本身是約 25 mm 的閉管,四分之一波長共振落在 2.5–3 kHz,這正是人耳最靈敏的頻段。

耳機「繞過」了這個系統的一部分:耳罩式保留大部分耳廓交互作用;入耳式則完全繞過耳廓,必須把缺失的 3 kHz 耳增益「做回」調音之中。

全課程最重要的心理聲學命題:耳膜處的目標響應,必須重建「優質音源在良好房間中、經過身體自身濾波後」原本會產生的結果。

2.2 心理聲學現象與設計後果

現象設計後果
等響曲線(ISO 226)小音量聆聽顯得單薄;動態響度補償 DSP 之依據

遮蔽效應低頻抬升會遮蔽中低頻細節;+6 dB 低頻棚即可使中頻「變糊」

目標曲線理論基礎評價與現況

3.2 腔體聲學:單體只是三分之一的故事

  • 集中參數模型:低頻時系統等效為電路 —— 腔體空氣彈簧與懸邊為電容、振膜質量與孔道空氣柱為電感、阻尼網與洩漏為電阻。設計者先建 SPICE 式模型(或 COMSOL / AKABAK)再開模。
  • 壓力腔效應:密閉前腔中,第一共振以下耳膜聲壓跟隨振膜位移 —— 密閉耳機 / IEM 可平直延伸至 20 Hz 以下,這是小房間喇叭做不到的。
  • 洩漏即高通:墊圈與頭部之間數 mm² 的縫隙即可削去 100 Hz 數 dB(戴眼鏡低頻變少的原因)。產品必須選邊:耐洩漏設計(預先開孔 + ANC 補償,如 AirPods Pro)或依賴密封(低頻最大化但對配戴敏感)。
  • 開放 vs. 密閉:開放式後波自由輻射,響應平滑、空間感佳,代價是零隔音與低頻滾降;密閉式得到隔音與低頻,代價是 200 Hz–1 kHz 腔體駐波,需以阻尼與幾何馴服。
  • IEM 特有:耳塞至耳膜之空氣柱半波共振(約 7–9 kHz)隨插入深度移動;導管內徑與阻尼(以 rayl 值規格化)是 BA 系統的「被動 EQ」。

3.3 測量與電氣匹配(精要)

  • 治具:IEC 60318-4「711」耦合器(IEM 標準,>8 kHz 有假影)→ GRAS / KEMAR(耳罩式與 ANC)→ B&K 5128(仿真耳道阻抗至 20 kHz,研究級新標準)。
  • 核心測量集:頻率響應與左右配對、THD 對頻率與聲壓、阻抗與相位、靈敏度、隔音與洩漏、脈衝響應 / CSD、群延遲(>20 ms 影響影音同步)。產線 100% 執行掃頻異音檢測(rub & buzz)。
  • 八分之一法則:訊源輸出阻抗 ≤ 耳機阻抗的 1/8;多路 BA IEM 阻抗可在 8–60 Ω 間擺動,高輸出阻抗訊源會可聞地改變其音色。
  • 功率預算:100 dB/mW 的耳機達 110 dB 峰值僅需 10 mW;83 dB/mW 的平板則需 ~500 mW —— 「需要耳擴」的物理定義。

3.4 ANC 與 DSP 系統

  • 前饋:外側麥克風「預測」入侵噪音;主要有效於 <1 kHz,怕風噪。
  • 回授:內側麥克風監聽耳內殘餘;頻寬較廣、能修正配戴差異,但有迴授嘯叫之穩定性風險。
  • 混合式:兩者兼備,旗艦標配;100–300 Hz 可達 30–45 dB 衰減。次級路徑(單體→耳)隨每次配戴改變,靠 FxLMS 自適應濾波與入耳校正音維持最佳化。
  • 物理極限:ANC 僅於 ~1–2 kHz 以下有效;高頻必須交給被動隔音 —— 總衰減 = 被動 + 主動。
  • DSP 堆疊:調音 EQ、心理聲學低音、動態響度、配戴自適應補償、空間音訊(IMU 頭部追蹤 + 個人化 HRTF)、通話波束成形與 AI 降噪。

4.1 人因工程:數據化的舒適

  • 人體計測基礎:頭寬、頭高、雙耳屏弧、耳廓高度(成人約 55–70 mm)、耳道尺寸與角度;各人種群差異使單一幾何難以全球通用 —— 3D 掃描資料庫已成大廠標配。
  • 夾持力窗口:耳罩式實務舒適區約總夾持力 3–6 N(145–155 mm 治具);>5–6 N 一小時內疲勞,<2 N 穩定性與低頻密封受損。壓耳式(on-ear)承受力更低 —— 壓力落在軟骨上。
  • 壓力 = 力 ÷ 接觸面積:舒適度與「峰值壓力分布」相關,而非夾持力本身;更大、更深、更軟的墊圈分散負載,耳廓絕不可觸及單體護網。
  • 重量:<250 g 近乎無感;300–400 g 需優異的頭帶分載(寬帶、懸吊);>450 g(部分平板)無論如何限制聆聽時長。耳殼深度造成的頸部力矩與克重同等重要。
  • 熱舒適:皮革墊圈鎖熱鎖濕但密封佳;織物透氣但洩漏低頻 —— 這是真實的聲學 vs. 舒適取捨,設計者必須拍板。

4.2 材料科學:振膜、磁體與殼體

  • 振膜品質因數 = 比模數(勁度 ÷ 密度)+ 內阻尼。材料階梯:PET/Mylar → PEN/PEEK 多層 → LCP → 生物纖維素 → 金屬箔(Al、Ti、Mg)→ 鈹(可用比模數最高;加工毒性與成本極高,Focal Utopia)→ 鍍層複合(DLC、CNT、「石墨烯」—— 行銷經常跑在物理前面:多數「石墨烯振膜」實為聚合物膜加鍍層)。
  • 磁體:燒結釹鐵硼 N48–N55 主流,磁通與耐溫互為取捨;平板磁性耗用大量磁材(其成本與重量之源);鐵氧體存活於入門線。磁隙潔淨度是良率關鍵 —— 0.5 mm 磁隙中一粒鐵屑就是一件退貨。
  • 殼體與結構:射出 ABS/PC(玻纖強化)、CNC / 沖壓鋁、壓鑄鎂(勁度 / 阻尼 / 重量三優,用於軛與障板)、不鏽鋼頭帶簧片;客製 IEM 以 3D 列印壓克力 / 尼龍殼體產業化。阻尼網(鋼、尼龍、微孔板)以 rayl 值像電子元件一樣被規格化採購。

4.3 結構機構與量產品質

  1. 單體廠:振膜熱成形、繞線與貼合、充磁、自動組裝;每顆單體皆測量分級,並以頻響配對為左右聲道(高階線 ±0.5–1 dB)。
  2. 整機組裝:腔體組裝與阻尼貼放(出乎意料地依賴人工手感)、墊圈、頭帶、線材或無線主板;每個關節都是異音風險 —— 機構噪音是正式規格。
  3. 端末 100% 檢測:迷你消音箱內掃頻:頻響遮罩、異音、極性、麥克風;每台數秒(Klippel / Listen SoundCheck)。
  4. 可靠度驗證:落下、翻滾、線材彎折 >10k 次、頭帶開合 >50k 次、汗液鹽霧、UV、−20/+60 °C 溫循、墊圈磨耗模擬;TWS 另有充電盒鉸鏈壽命、電池循環、IP 水槽實測。
  5. 永續與可維修:電池與墊圈的壽命遠短於單體 —— 膠合電池使 TWS 淪為拋棄式品類;歐盟電池法規與 Fairbuds(可換電池)、HD 25/HD 600(全件可換)指出方向。可換墊圈同時是聲學壽命:墊圈老化即調音漂移。

Appendix A

核心術語表

耳增益 Ear gain
外耳對正前方聲源施加之 ~2–4 kHz 增益;耳機調音必須重建之。
HRTF
頭部相關轉移函數 —— 隨方向而異的耳 / 軀幹濾波。
擴散場 Diffuse field
全方向等能量之聲場;DF 目標曲線之基礎。
Harman 目標
以受控偏好測試導出之耳膜響應曲線(OE 2018 / IE 2019)。
壓力腔效應
密閉腔內低頻聲壓跟隨振膜位移 —— 耳機獨有的低頻延伸機制。
分割振動 Break-up
振膜停止活塞運動、進入模態彎曲之頻區。
動鐵 BA
平衡銜鐵換能器;IEM 與助聽器之微型單元。
rayl
比聲阻抗單位;阻尼網之規格語言。
夾持力 Clamping force
頭帶施加之總內向力(牛頓);舒適窗口約 3–6 N。
CMF
色彩(Color)、材料(Material)、表面處理(Finish)之工業設計方法。
次級路徑 Secondary path
ANC 中單體至耳膜之轉移函數;隨配戴改變,需自適應濾波追蹤。
FxLMS
自適應 ANC 之核心演算法家族。
堵耳效應 Occlusion
密封耳道放大骨導自聲之現象。
JND
恰可辨差;人耳可分辨之最小差異,決定工程公差。
五構面分析法
本課案例研究工具:脈絡 / 聲學 / 工業設計 / 商業 / 傳承。
Chi-Fi
中國新興高性價比發燒音訊生態;以公開測量為共同語言。
